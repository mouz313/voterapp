🏛️ Pakistan Electoral Hierarchy Architecture

The platform models the complete constitutional and local government election framework of Pakistan:

Level 1: Federal & Provincial

National Assembly (NA): NA-1 to NA-266. Contains $\ge$ 2 Provincial seats (PP in Punjab, PS in Sindh, PK in KPK, PB in Balochistan).

Level 2: Administrative

District $\rightarrow$ Tehsil $\rightarrow$ Union Council (UC). UCs represent local government wards mapped to national & provincial seats.

Level 3: Polling & Voters

Polling Stations & Block Codes. Houses registered voters with Urdu Name, Father Name, CNIC, Silsala #, and Gharana #.

📱 Candidate Monetization & Device Limit Control

The commercial core of the business model is selling UC-level mobile app licenses to candidates.

1

Account Creation & UC Locking

Admin registers candidate with Email, Password, Assigned UC (e.g. UC-14), and unlimited authorized mobile handsets.

2

Automated Registration & Hardware UUID Authorization

When polling workers log in, the API captures their phone hardware UUID and authorizes the device without artificial login caps.

3

1-Click Live Revocation Console

Admin can view every logged-in phone's model name, IP address, and last active timestamp, and revoke any rogue device instantly.

POST /api/v1/sync/searches
Background Sync

Silent background sync payload sent by the mobile app whenever an internet connection is detected.

Request Body (JSON)
{
  "device_uid": "UUID-9876-5432-ABCD",
  "searches": [
    { "query_type": "cnic", "results_count": 1, "searched_at": "2026-09-01 14:30:00" },
    { "query_type": "gharana", "results_count": 6, "searched_at": "2026-09-01 14:32:00" }
  ],
  "batch_count": 45
}
Response (200 OK)
{
  "status": true,
  "message": "Search telemetry synced successfully.",
  "synced_count": 45
}
POST /api/v1/sync/heartbeat
Telemetry

Background ping updating device last-seen timestamp, IP address, and app version.

🗄️ Relational Database Schema

Table Key Columns Relationships Description
national_assemblies id, code, name, province hasMany(ProvincialAssembly, UC) NA-1 to NA-266 federal seats
provincial_assemblies id, national_assembly_id, code, name belongsTo(NA), hasMany(UC) PP/PS/PK/PB provincial seats
ucs id, tehsil_id, national_assembly_id, name hasMany(Voter, BlockCode, PollingStation) Union Council administrative unit
users id, role, uc_id, max_devices, status hasMany(CandidateDevice, SearchLog) Candidate accounts & Admin credentials
candidate_devices id, user_id, device_uid, is_revoked belongsTo(User) Mobile hardware locks & last active times
voters id, uc_id, cnic, silsala_no, gharana_no belongsTo(UC, BlockCode, PollingStation) Electoral roll voter records
